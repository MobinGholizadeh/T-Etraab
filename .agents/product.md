# Product Goal & Context

## Project Overview
The AI Task Management Platform is an AI-powered system designed to facilitate task management through a natural language interface. It integrates with task providers (like Plane) and leverages AI models (via Groq) to process user inputs efficiently.

## Core Objectives
- Provide a seamless task management experience via a Telegram bot interface.
- Automate and queue background tasks robustly using Celery and Redis.
- Ensure high observability and easy deployment using Docker, Prometheus, and Grafana.

## Target Audience
Individuals and teams needing quick, conversational access to task creation, updates, and tracking directly from messaging apps.
