# Technology Stack

## Core Language
- **Python 3.10+**

## Frameworks & Libraries
- **FastAPI**: Backend REST API framework.
- **Uvicorn**: ASGI web server for FastAPI.
- **Pydantic**: Data validation and settings management.
- **Aiogram**: Asynchronous framework for Telegram Bot API.

## Background Processing & Caching
- **Celery**: Distributed task queue.
- **Redis**: In-memory data structure store used as a message broker for Celery and caching.

## AI & Integrations
- **Groq**: Fast LLM API integration.
- **OpenAI Whisper**: Speech recognition/transcription (if voice messages are supported).
- **Plane**: Task management platform integration.

## Monitoring & Observability
- **Prometheus**: Metrics collection.
- **Grafana**: Metrics visualization and dashboards.
- **Python JSON Logger**: Structured logging.

## Infrastructure
- **Docker & Docker Compose**: Containerization and local development orchestration.
